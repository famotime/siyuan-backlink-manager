# 思源笔记「反链管家」插件功能简介

「反链管家」是一款为思源笔记量身定制的反链管理增强插件，旨在解决原生反链面板“上下文不清晰”与“交互过于复杂”的核心痛点，让双链笔记最初承诺的那种自由，真正落到日常里。

## 核心功能特性

### 1. 渐进式上下文展开 (Progressive Context)
打破原生反链面板固定且容易产生“内容黑洞”的展示方式，提供 4 种可随时切换的上下文状态，满足不同的整理需求：
- **核心**：仅展示真正打到反链的那一行/块，快速定位命中位置。
- **近邻**：在核心基础上补足前后文，帮助理解语境。
- **扩展**：根据文档结构向外延展（如展开整个标题节，或展示列表的同级与父子层级）。
- **全文**：直接查看完整的原始文档内容，彻底消除上下文焦虑。

### 2. 沉浸式免跳转编辑 (In-place Editing)
在整理笔记时，大多数情况下无需跳出当前反链界面，可直接在面板/页签中与主窗口的主题笔记进行双向编辑、剪贴操作，最大程度上保持整理心流不中断。

### 3. 按来源文档聚合 (Aggregated View)
按来源文档聚合反链，每次只展示并处理一个反链块。引导用户一条一条专注处理线索，而非同时面对十几条碎片信息，减轻认知负担。

### 4. 极简与统一的交互设计 (Unified Interaction)
砍掉增加心智负担的冗余岔路，保留最高频、最符合直觉的交互：
- **统一视图**：将原本分离的“反链页签”和“反链面板”收束为统一界面。默认保持视图稳定，通过右上角“刷新”按钮按需跟踪当前文档，兼顾稳定性与灵活性。
- **直觉点击**：重新分配标题点击逻辑：左键点击在主窗口打开，右键点击在右侧页签打开，无需记忆复杂的键盘组合键。
